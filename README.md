# 🌐 Language Translator 🎙️

A web-based Language Translator that supports translation between 15 languages. It accepts both text and voice input and provides text and voice output, making communication easier.

## ✨ Features

* 🌍 Supports 15 languages
* ⌨️ Text input for translation
* 🎙️ Voice input using speech recognition
* 📝 Displays translated text
* 🔊 Voice output for translated text
* 💻 Simple and user-friendly interface
* ⚡ Easy to use

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `translator.html` in your web browser.
4. Select the languages.
5. Enter text or use voice input.
6. Get the translated text and voice output.
